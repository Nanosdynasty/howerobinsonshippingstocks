# Maritime Stock Terminal

A high-fidelity dashboard for tracking global and regional shipping stocks (Container liners, Dry Bulk, Oil Tankers, Ports and Logistics). The application integrates direct Yahoo Finance data with TradingView widgets to display:
*   **Daily rates** (Current stock prices)
*   **Last day rate** (Previous daily close prices)
*   **Week-on-Week changes** (Percentage and nominal metrics)
*   **20-Year Historical Performance** (Via interactive monthly time-series graphs powered by Chart.js and full technical charting powered by TradingView)
*   **Vessel Fleet Profiles & Sector Statistics**

## How to Run

1.  **Launch the terminal server**:
    Run the following command in your terminal inside this directory:
    ```powershell
    node server.js
    ```
2.  **Access the application**:
    Open your browser and navigate to:
    [http://localhost:8080](http://localhost:8080)
